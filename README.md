
Microbial analysis: 16S human oral metagenomics
This repository contains a reproducible workflow for analyzing human oral 16S rRNA amplicon sequencing data.

Project contents
data/metadata/: sample metadata (metadata.tsv)
data/processed/: processed feature table + taxonomy
scripts/: analysis scripts
results/: figures and summary tables
docs/: methods and notes
Notes
Raw FASTQ files are not uploaded to GitHub.
